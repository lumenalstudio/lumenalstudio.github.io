# lumenalstudio.com

Static site for Lumenal Studio LLC. No build step: plain HTML and CSS, hosted on GitHub Pages.

- `index.html`: studio home page
- `isoliminal/index.html`: Isoliminal coming-soon page (lumenalstudio.com/isoliminal)
- `404.html`: not-found page
- `CNAME`: custom domain for GitHub Pages
- `assets/`: CSS, fonts (Krona One and Space Grotesk, both under the SIL Open Font License), logo and icons

To edit, change the HTML and push. GitHub Pages redeploys within about a minute.
